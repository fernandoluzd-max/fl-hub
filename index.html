Dúvidas rápidas.

O que é o Base FL?

É um app para computador que reúne os meus kits para o CapCut e as minhas ferramentas para atender cliente. Você instala uma vez e tudo o que comprar aparece ali.

Preciso comprar tudo?

Não. Você compra só o que fizer sentido. Os Títulos Dinâmicos já vêm com o CaseUp e o ChronoCut de bônus. As quatro ferramentas de atendimento vêm juntas, no Kit Freelancer.

O app é pago?

Não. O app é gratuito. Os kits e as ferramentas que ficam dentro dele é que são comprados, um a um.

Funciona no celular?

As ferramentas abrem no navegador, no computador ou no celular. Os kits para o CapCut são só para o CapCut do computador (Windows e Mac).
